# 情绪记账 · 钱流向了哪种情绪

> 「我知道我没乱花，可钱就是没了。」

一个**为「想记账但每次都放弃的人」**做的极简工具。纪念碑谷式宁静视觉，柔和动画与音效。
不要求你记每一笔——每月只做一件小事：**给几笔大额支出打个情绪标签**，月底它就告诉你：钱，是被什么情绪拿走的。

- 在线网址（GitHub Pages）：https://dongqianqi-888.github.io/emotion-ledger/
- 风格参考：纪念碑谷 —— 极简、低饱和、宁静；缓慢漂浮的几何、柔和的进场动画、程序生成的轻提示音（无需任何音频文件）。

## 它解决什么问题

| 痛点 | 这个工具怎么应对 |
| --- | --- |
| 记账 App 要求记每一笔，坚持三天就崩 | 每月只打 **5–10 笔**大额支出的情绪标签，两分钟搞定 |
| 银行流水有「餐饮 -38」，但没「为什么」 | 流水的维度是**类别**，人的维度是**动机**——工具补上动机这一层 |
| 失控的是小额高频的情绪性支出 | 重点捕捉非固定的大额消费，把情绪和**触发场景**连起来 |
| 现有方案给完饼图只剩自责 | 交付的不是报告，是一条**可执行的行动**和一句**安慰** |

## 三步流程

**第一步 · 导入与概览**
- 上传 / 粘贴你的账单（CSV 或纯文本），自动识别「日期 / 金额 / 描述」并归类；
- 也可以直接走内置的示例流程体验完整路径。
- 先给你一张「支出大类」分布图，看清钱大致花在哪。

**第二步 · 情绪标记**
- 先勾掉**住房 / 交通 / 通讯 / 医疗**等固定支出（可改、可加减）；
- 系统自动挑出 **Top 10 大额非固定支出**，你给每笔选一个情绪 + 1–5 强度分；
- 也支持手动补一笔。

**第三步 · 看清了**
- 一张「情绪塔」卡：钱按金额占比流向了哪些情绪（如 犒赏 32% / 焦虑 28% / 社交 21%）；
- 再加一句**场景洞察**（如「你的焦虑型消费集中在周三晚上和周日，多在加班之后」）；
- 一句**给自己的话** + 一个**可试的小动作**。

## 如何导入你的账单

工具能自动识别常见中英文列名（日期 / time / 描述·备注·摘要·商户 / 金额·amount 等）。
最省事的做法：导出的 CSV 至少包含这三类信息——

```csv
日期,描述,金额
2026-10-01,星巴克拿铁,38.00
2026-10-02,京东-机械键盘,299.00
2026-10-03,地铁充值,50.00
```

- 支持带引号、含逗号的字段（如 `"淘宝,卫衣",299`）。
- 支出为正、收入为负均可识别；固定支出（住房/交通等）会自动归类，可在第二步里勾掉。
- 不同银行表头差异大——如果解析不准，把它贴给我，我把识别规则补稳。

## 技术架构

- **纯前端单文件**：HTML + 内联 CSS + 内联 JS，零依赖、零构建。
- **音频**：Web Audio API 实时合成——
  - 舒缓连贯的背景音乐（两层柔和铺底 + 长音符 legato 琶音）；
  - 情绪强度 1–5 对应五声音阶由低到高，强度越大调子越亮；
  - 每种情绪有专属根音，反馈更有「读心」感。
- **数据**：localStorage 持久化。
- 右上角 `♪` 是总开关，关掉背景音乐和音效一起停。
